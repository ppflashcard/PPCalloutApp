Privacy notice: Consumer Key, Consumer Secret, passwords, and session IDs are never saved to disk, a database, cookies, or browser storage. They exist only in memory for the minimum time needed to connect. Closing this tab or clicking Log Out clears them from the browser and server immediately.

Best for SSO-enabled orgs. You sign in through Salesforce (including your corporate SSO), and the app receives a refresh token so access is renewed automatically — no browser session ID needed.

  1. In Salesforce, create or edit a Connected App with OAuth enabled.
  2. Set the callback URL to the exact value shown below (copy it into your Connected App).
  3. Loading callback URL…
  4. Enable Refresh Token under OAuth scopes.
  5. Enter your Connected App details below, then click Sign in with Salesforce.

Session IDs from Lightning pages do not work for REST API calls. Follow the steps below.

  1. Paste your org Instance URL below (e.g. https://yourorg.develop.my.salesforce.com).
  2. Click Open API page — this opens the REST endpoint in a new tab.
  3. On that new tab: F12 → Application → Cookies → select the develop.my.salesforce.com domain → copy the full sid value.
  4. Paste sid here and connect immediately. Do not use document.cookie in the Console — sid is HttpOnly.
